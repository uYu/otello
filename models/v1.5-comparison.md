# v1.5：32 通道、2 个残差块

本轮训练了 32 通道、2 个残差块的价值网络，保留当前行棋方/对方两张 8×8 输入。30 轮训练使用同一百万局面缓存、验证/测试各 6,000 局面，按最低验证 MSE 选择第 24 轮权重。训练使用本机 Metal GPU，推理与对战使用 CPU。

网络为 `Conv3×3(2→32)/BN/ReLU → 2×[Conv3×3(32)/BN/ReLU/Conv3×3(32)/BN/相加/ReLU] → Conv1×1(32→1)/BN/ReLU → Flatten64 → Linear64/ReLU → Linear1/tanh`。训练参数 42,019 个，BN 折叠后的推理参数 41,858 个，FP32 文件 167,460 字节。4 块版本的导出与推理有测试，本轮没有训练 4 块模型。

| 指标 | v1.3 NNUE | ResNet32×2 |
| --- | ---: | ---: |
| 测试集平均绝对子数误差 | 10.167 | 9.832 |
| 验证集平均绝对子数误差 | 10.682 | 10.338 |
| 完整估分中位耗时 | 1.434µs | 102.897µs |
| 50ms 对战非精确回合平均完成深度 | 7.37 | 3.11 |
| 50ms 对战节点/秒 | 2,034,585 | 14,298 |

完整估分测试使用同样的 16 个局面，7 轮、每轮 4,096 次，含 Python/C ABI 开销。这里 NNUE 包含完整累加器重建，而搜索中使用增量更新；不能把 71.75 倍完整估分耗时比直接当作搜索节点成本比。

双方每步各 50ms、交换黑白各 50 局、从标准初始棋盘自行走棋，ResNet **2 胜、0 平、98 负**，平均少 37.87 子。双方均使用 v1.3 前 12 手近分加权开局策略，没有指定开局、开局库或其他引擎兜底。正式对战 100 局共 6,174 个动作已独立重放并核对种子、加权选择、子差和聚合统计。

补充的双方 3 秒试验在用户改为“1 秒、四种模型/搜索组合”后停止。未完成的原始文件只记录了 3 局完整对局；详见其 `complete=false`、`plannedGames=4` 和冻结基线的停止说明。不要将它视为已完成的 4 局试验。当前四组合结果见 [v1.6 对照](v1.6-comparison.md)。

6,000 个测试局面的 Python/C++ 推理对照通过，最大未取整差 0.499917 分（满尺度 1,000）。原生、ASan/UBSan、13 项训练测试、12 项 Wasm 测试和前端构建均通过。离线估分改善没有在 50ms alpha-beta 中转化为优势，默认模型保留 v1.3。
