# v1.4：8×8 小 CNN 实验

结论：本次小 CNN 不替换 v1.3。100 局各 50ms、交换黑白、标准初始棋盘自行走棋，CNN **4 胜、0 平、96 负**，平均少 30.28 子。双方使用相同的 v1.3 开局随机策略（12 手、温度 32、近分窗口 64、线性衰减），没有指定开局、开局库或其他引擎兜底。

## 模型与训练

输入为行棋方/对方两张 8×8 棋盘；网络为 `Conv3×3(8) → ReLU → Conv3×3(8) → ReLU → Flatten512 → Linear32 → ReLU → Linear1 → tanh`，17,185 参数、FP32、68,764 字节。v1.3 使用 v1.2 的 33,537 参数 NNUE。保留棋盘形状不代表扩大模型；这个 CNN 的参数量反而更小。

复用同一百万训练局面缓存和各 6,000 个验证/测试局面，缓存 SHA-256 为 `ed971def0db9636494a8c1fe46f9b86fb053adfe546b62e699b463282c4c8ec6`。种子 20261027，CPU 2 线程，30 轮、batch 1024、AdamW 学习率/weight decay 均为 0.001；按最低验证 MSE 选择第 25 轮，在正式对战前冻结。未利用对战结果挑权重。

| 指标 | v1.3 NNUE | 小 CNN |
| --- | ---: | ---: |
| 测试集平均绝对子数误差 | 10.167 | 10.635 |
| 验证集平均绝对子数误差 | 10.682 | 11.167 |
| 直接 C ABI 完整估分中位耗时 | 1.420µs | 3.172µs |
| 对战搜索节点/秒 | 2,114,698 | 601,531 |
| 非精确求解回合平均完成深度 | 7.41 | 6.23 |

直接估分测试含 Python/C ABI 开销，NNUE 包含完整累加器重建；实际搜索 NNUE 使用增量更新。因此 2.23 倍的完整估分耗时比不等于搜索每个节点的成本比。对战节点吞吐量还受搜索路径、剪枝等影响。

## 同深度诊断

另做 20 局双方固定最大深度 4 的对战，每步 60 秒保护上限，所有非精确求解回合都完成了深度 4。CNN **6 胜、0 平、14 负**，平均少 18.6 子。这支持估分质量和固定时间下搜索较浅共同影响结果的解释，但样本小、深度浅，不能用两个胜率相减来量化各因素的影响。

正式对战 100 局独立逐步重放共 6,145 个动作，诊断 20 局共 1,206 个动作；均核对合法性、终局子差、双方种子/权重抽样与统计。正式对战有 51 种完整棋谱（保留初始黑白布局的对称去重后仍为 51 种）、41 种前 12 手路径。重复轨迹仍然存在，不作独立样本或 Elo 推断。

追加核对了全部 6,000 个测试局面的行棋方视角：输入先排列当前行棋方/对方，标签是最终黑方子差乘以当前行棋方符号，搜索逐层反号。黑走 3,083 个局面误差 10.54 子，白走 2,917 个局面误差 10.73 子；强行反转输出符号分别恶化至 17.56、17.86 子。同时交换颜色和行棋方时输出完全一致。全量 Python/C++ 对照有 4 个局面因浮点累加跨越整数取整边界而相差 1 分（满尺度 1,000），最大未取整差 0.50197 分；没有发现评分视角颠倒。这些检查不替代去掉该特征并重新训练的因果对照。见 [行棋方核对记录](v1.4-turn-perspective-audit.json)。

## 对照 AlphaGo 论文

2016 年 AlphaGo 的策略网络有 12 个隐藏卷积层，比赛版本每层 192 通道，另有价值网络；策略提供落点概率，价值预测胜负，配合 MCTS 和快速模拟。训练包括人类落点监督、自我对弈强化学习及自我对弈胜负回归。[原论文 Methods / Figure 1](https://storage.googleapis.com/deepmind-media/alphago/AlphaGoNaturePaper.pdf)

2017 年 AlphaGo Zero 使用共享残差主干：一个卷积模块加 19 或 39 个残差块，256 通道，每个残差块含两层卷积、批归一化和跳连；随后分策略头和价值头。策略头输出 361 个落点加 pass，价值头输出胜负期望。训练目标同时拟合 MCTS 的落点分布和自我对弈胜负。输入为历史棋盘和行棋颜色共 17 个平面，历史信息与围棋重复局面规则有关，不能据此认为黑白棋必须复制 17 个输入平面。[原论文 Methods / Figures 1、4](https://www.idi.ntnu.no/emner/it3105/materials/neural/silver-2017.pdf)

本轮没有残差块、策略头、胜负目标、自我对弈训练或 MCTS，只把旧搜索的叶节点评分替换成小 CNN。因此结果只否定这套具体配置，不能否定 CNN 或 AlphaGo 式设计。可作为下一轮候选的缩小设计是：8×8 输入、32 通道、2–4 个残差块、65 维落点/pass 策略头与胜负价值头。这是针对本项目的待验证方案，不是论文原配置，也没有战力保证。若先保留 alpha-beta，策略头可用于落点排序；若采用 AlphaGo Zero 的训练闭环，还需匹配 MCTS 和自我对弈数据流程。
