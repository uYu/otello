# v1.9 胜负价值候选：每步 1 秒、20 局

对冻结 v1.8，候选取得 **18 胜、2 平、0 负，得分率 95.0%**，平均子差 +2.80。默认模型仍为 v1.8，候选尚未获批准提升。

## 改动与训练

共享特征层、策略分支及其量化字节与 v1.8 完全相同，只重新训练 512→1 tanh 价值头的 513 个参数。将原缓存最终子差取符号，标签为行棋方胜 +1、平 0、负 −1，价值损失为 MSE。训练集 1,000,000 局面、验证／测试各 6,000 局面，沿用冻结的开局分组与来源。30 轮中验证最优为第 3 轮，训练耗时 37.68 秒；测试量化胜负 MSE 0.712702，非平局符号准确率 67.12%。该标签来自已有棋谱，不是自我对弈或 MCTS 访问分布监督。

采用 OTNNUE4 明确区分目标。叶节点与终局均回传胜／平／负语义；求解器发现已证明的必胜分支即可证明父节点必胜，选择时区分已证明分支与四舍五入为 1 的网络估计。旧子差模型继续走原分支。这轮结果包含价值目标、匹配的终局回传和证明停止行为的共同影响；固定探索系数 1.5 不变，并不意味着两个奖励尺度下探索强度完全等价。

## 对战协议与结果

从标准初始棋盘开始，无开局库，每步双方各 1,000ms，20 局交替黑白；每两局共享种子。v1.8 使用与已批准基线 SHA-256 完全一致的独立原生参考库，候选使用隔离构建。策略先验、开局抽样规则、树复用配置不变。20 局完整棋谱共 1206 步，规则与根选择均逐步审计。

| 指标 | v1.9 胜负候选 | v1.8 |
| --- | ---: | ---: |
| 胜 / 平 / 负 | 18 / 2 / 0 | 0 / 2 / 18 |
| 得分率 | 95.0% | 5.0% |
| 平均子差 | +2.80 | -2.80 |
| 平均每步耗时 | 759.4ms | 921.4ms |
| 平均每步模拟数 | 307,792 | 3,332,346 |

模拟数和深度受价值目标、证明停止和树复用影响，不直接代表棋力。当前仅是单预算、20 局的小样本，从同一初始棋盘出发也可能重复走子路径，不能据此推算 Elo 或保证其他预算下的收益。

## 校验与复现

- 1,024 局面量化／C++ 价值误差至多 0.4995 个整数评分单位；策略概率误差为零。
- 24 个真实测试局面、固定 512 次模拟，新库加载旧 v1.8 模型与冻结参考库的落点、评分、根候选、选择信息、访问数及搜索统计完全一致，计时除外。
- 原生测试及 ASan／UBSan 通过；3 项胜负训练／格式／精确选择测试及原 8 项 NNUE 测试通过。
- 实测源码保存在 `archive/v1.9-outcome-sources.*`。后续精简监控、增加棋盘遥测以及头文件注释修改未参与本轮实测，不改写归档。

运行 `python3 scripts/verify-outcome-experiment.py` 核对模型、归档和完整对局。复现命令见 `docs/TRAINING.md` 的 v1.9 节；监控为 `sh scripts/watch-outcome.sh`，`--details` 展开搜索统计。模型来源与原始数据许可继续遵循 `data/README.md`。
