# v1.41：WTHOR-only，Elo 阈值比较与等权聚合

按用户要求，训练来源只保留 WTHOR，排除原始 train split 的 60,775 盘 Logistello 独立语料；不按 Elo 加权聚合。原始 6,000 验证与 6,000 测试的棋盘、行棋方、结果和策略标签全部保留，没有改成 WTHOR-only holdout。

规则为：双方已知、且年初 train-only 内部 Elo 均严格低于阈值才剔除；恰好等于阈值保留。605 盘至少一方评级未知的训练棋局另行计数并保留，不把未知当低分。评级来自冻结 v1.40 重放，不用全语料最终分，不在筛选后重新计算 Elo。

选择 1600 作为过滤候选：预先规定至少保留 WTHOR-only 棋局数与唯一局面数的 60%，再在满足规模下限的候选中选择训练棋谱的实战/24空位理论 WDL 不一致率最低的一档。这个代理量只衡量一个残局截面的结果一致性，不是逐着失误率，也不是棋力证据；没有用验证/测试模型分数挑阈值。

1600 保留 51,854 盘、801,612 次出现、664,495 个局面；剔除 WTHOR 的 28,707 盘。1650 再少 8,044 盘、105,171 个局面，不一致率仅从 22.04% 降到 21.93%。1300 则只删 60 盘，过滤力度很小。

全量 WTHOR 有 18,328 个多走法轨道局面、20,706 个多结果局面；1600 候选仍保留 12,135 个多走法轨道、14,512 个多结果局面，继续保存全部计数，而非只取首个标签。

所有保留出现的质量都是 1，不导入 v1.40 的 Elo 加权概率或质量字段。D4 稳定子等价动作平分一条记录的质量，属于对称处理，不是 Elo 加权。每个唯一局面的策略损失权重恰好为 1；软价值为未加权实战胜率减负率，辅助顺序为胜/负/平。

原百万训练行中有 529,583 行的局面仍在 1600 候选中。`matched_train_group` 对缺失行使用 -1；应使用 `matched_train_row` 与 `matched_retained_group` 的有效配对视图，不能将 -1 当作 Python 的最后一行索引。

WTHOR 官方说明收集欧洲和世界各地高水平赛事，但不能据此保证每盘双方都是职业棋手或高手。本地 WTHOR 也有程序参与者；本轮按来源排除 Logistello 独立语料，没有凭棋手名字把 WTHOR 里的程序参赛记录另删。[FFO 官方介绍](https://www.ffothello.org/informatique/la-base-wthor/)。

完整逐局保留/剔除原因、过滤后的出现记录和稀疏聚合数据保存在 `.build/training/wthor-elo-v1.41/`。已独立核验 141,336 条原始训练棋谱的过滤决定、801,612 条候选出现、全部胜负计数和 200 个局面的动作质量；Logistello 出现为 0，非法动作和 holdout 交叉均为 0。验证/测试全部数组及策略标签哈希不变。

本数据版本没有训练模型。用户随后要求先训练无 Elo 过滤的 WTHOR 全量版（v1.42，对称共享原结构），再训练 1600 版（v1.43，同结构）；结果各自独立记录，不能把这里的数据选择代理量当作训练结果。
