# 配对乘积 NNUE 离线实验

shared 128->256 clipped linear transform per view; product splits 256 into halves and computes 128 rounded products per view; value 256->1 and policy 256->32->65; control uses original 512-dimensional dual-view heads

Product changes interaction and compresses head input 512 to256; not a pure multiplication-only ablation. Same-protocol fully trained linear control is included.

原百万局面、冻结验证/测试集；普通NNUE与乘积NNUE均从头QAT联合训练30轮，相同数据增强顺序与超参数。默认保持v1.9，尚未对战。
