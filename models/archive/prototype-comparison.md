# 256 维模型与非模型评分对比

2026-10-27，本机原生 Release 构建；256 维首轮实验模型与原有启发式评估对战。两方使用同一个 PVS/TT/历史排序搜索框架，**仅更换叶节点评分**，均关闭开局库。

20 个固定随机种子生成的 8 步开局，每个交换黑白，总计 40 局；双方每步上限 50ms、最大 64 层，完整迭代结束才发布候选结果。种子 `20261027`。部分残局提前搜完，所以平均实际用时约 39ms。

| 指标 | NNUE 256 | 非模型启发式 |
| --- | ---: | ---: |
| 胜 / 和 / 负 | **28 / 0 / 12** | 12 / 0 / 28 |
| 得分率 | **70%** | 30% |
| 平均最终子差 | **+8.3** | -8.3 |
| 平均完成深度 | 6.82 | 8.17 |
| 平均每步实际耗时（含接口与分配） | 39.38ms | 39.59ms |
| 实际搜索节点 / 秒 | 约 143 万 | 约 648 万 |

本轮模型版用更少的搜索节点、较浅的搜索取得更高得分。节点速度包括整次搜索开销，不能等同于纯网络推理耗时。这里对比的是当前同一搜索框架下两种评分，不包含 Egaroucid，也不是升级前后所有算法的混合对比。

这是单个模型、单种短时控制和 20 个开局的初测，尚无稳定 Elo 或多时间档结论。模型只训练了 48,000 个训练局面，不能据此声称超过成熟黑白棋引擎。

完整开局、逐手棋谱、颜色、结果和搜索统计见 [prototype-comparison-50ms.json](prototype-comparison-50ms.json)，模型训练元数据见 [nnue256-prototype48k.json](nnue256-prototype48k.json)。此页记录的是 48,000 训练局面的历史原型。

```sh
python3 scripts/compare-evaluators.py \
  --model models/archive/nnue256-prototype48k.otnnue \
  --games 40 --milliseconds 50 --seed 20261027 \
  --output .build/training/comparison-repeat.json
```

时间限制搜索会受机器负载、编译器和计时波动影响；相同种子和开局不保证逐手完全相同。
