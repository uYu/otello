# NNUE 256 v1 基线实验

模型已完成 100 万个训练局面的训练，权重在对局前冻结。模型结构为 128→256→1，33,280 参数，67,096 字节；同一测试集的平均子差误差为 10.58 子，原型为 11.24 子。

本次按用户要求记录两组实验，每组 100 局，双方每步 50ms、最大 64 层，从标准初始局面开始，交替执黑/白：

1. 纯搜索 vs 模型搜索：相同 PVS/TT/历史排序框架，更换启发式/NNUE 评分。
2. 模型搜索 vs 模型搜索＋开局库：两方使用相同 NNUE 权重，仅一方启用 Egaroucid 开局库；查库未命中时调用同一 NNUE 搜索。开局库加权随机等级为 1，允许最多 2 个评分单位差距；书本选择按对局/步数种子重现。

## 已冻结结果

| 实验 | 统计视角 | 胜 / 平 / 负 | 得分率 | 平均子差 |
| --- | --- | ---: | ---: | ---: |
| 实验一：纯搜索 vs 模型搜索 | 模型搜索 | **100 / 0 / 0** | **100.0%** | +40.92 |
| 实验二：模型搜索 vs 模型搜索＋开局库 | 模型搜索＋开局库 | **62 / 4 / 34** | **64.0%** | +1.35 |

第二组累计开局库命中 **893 次**，未命中后执行同一模型搜索 **2,107 次**。全部 200 局已由原生规则重放，复核终局、胜负和选步来源。冻结清单见 [v1-baseline.json](v1-baseline.json)。

两组已完成；监控命令可查看最终统计或跟踪下一次运行：

```sh
cd otello
python3 scripts/watch-matches.py
```

第一组从“模型搜索”视角统计，第二组从“模型搜索＋开局库”视角统计。退出监控不会停止对局。

逐局报告：[纯搜索 vs 模型搜索](v1-search-vs-model.json)、[模型搜索 vs 模型搜索＋开局库](v1-model-vs-book.json)。每局保留完整落子与停着、选步来源、查库命中/未命中及搜索统计；运行中先写实时状态和已完成局面，完成后标记 complete。

模型/数据/实验设置见 [v1-baseline-protocol.json](v1-baseline-protocol.json)、[nnue256-v1.json](nnue256-v1.json)、[v1-dataset.json](v1-dataset.json)。

固定初始局面的重复对局用于本机固定预算基准，不能当作不同开局的独立样本，也不用于推导 Elo。时间限制搜索会受机器负载与计时波动影响。历史原型的随机开局实验见 [原型记录](archive/prototype-comparison.md)。
